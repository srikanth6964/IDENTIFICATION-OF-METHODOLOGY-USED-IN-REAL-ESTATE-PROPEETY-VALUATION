# House Price Prediction

## Overview
House Price Prediction is an end-to-end **machine learning project** that predicts house prices based on key features such as **number of convenience stores**, **house area**, and other factors.  
The project includes model building in Google Colab, saving the trained model as a **pickle file**, and running predictions through a Python app (`app.py`) in VS Code/Anaconda.

## Tech Stack
- **Languages & Libraries:** Python, Pandas, NumPy, Scikit-learn  
- **Tools & Platforms:** Google Colab, VS Code, Anaconda  
- **Deployment:** Pickle for saving the model, Python app for predictions  

## Project Structure
- `HousePricePrediction.ipynb` – Colab notebook with model building and analysis  
- `app.py` – Python app to run predictions  
- `model.pkl` – Trained regression model  
- `README.md` – Project documentation
